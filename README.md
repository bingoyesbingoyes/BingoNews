# BingoNews

A beautiful, Apple-style news aggregator with drag-and-drop organization, built with Tauri.

## Features

- 📰 Organize news sources by category
- ✅ Checkbox selection for batch opening
- 🔄 Drag & drop to reorder items and categories
- 📁 Drop files/apps from desktop to add (Tauri desktop app)
- ✏️ Inline editing of names
- 💾 Auto-save to localStorage
- 🖥️ Cross-platform desktop application


### Desktop App (Tauri)
- **Drag & Drop**: Drop files, folders, or applications directly from Finder
- **Full Path Support**: Automatically detects complete file paths
- **Native Performance**: Fast, lightweight desktop application
